# The Correspondence Studio

Build an AI Email Generator web application with a clean, professional, "letterhead correspondence" aesthetic. Users select an email type (Job Application, Apology, Meeting Request, Thank You, Business Inquiry), enter recipient info, purpose, key details, tone, and length, then click Generate Email to produce a draft via AI. Include a Prompt Library section with pre-built prompts for each of the five email types — viewable in a modal and applicable to the form with one click. Provide Copy, Regenerate, and Clear actions on the generated draft. Layout: two-column compose/output on desktop, single column on mobile. Visual direction: deep navy ink text on a cool paper-grey background, a wax-seal red as the primary call-to-action color, and a muted gold as a secondary accent — evoking formal correspondence/stationery rather than a generic SaaS dashboard. Display type in a serif (Fraunces), body/UI in a sans (Inter).
